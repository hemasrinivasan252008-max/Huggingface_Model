#  Python LLM Chatbot using Hugging Face

A simple **Large Language Model (LLM) chatbot** built using Python and the Hugging Face Inference API.

This project allows the user to enter a question directly in the terminal. The question is sent to a Hugging Face-hosted language model, and the generated response is displayed in the terminal.

---

##  Project Overview

This project demonstrates how to connect a Python application with a Large Language Model using the **Hugging Face Hub**.

The application:

1. Takes a question from the user.
2. Uses a Hugging Face Access Token for authentication.
3. Connects to the Hugging Face Inference API.
4. Sends the user's question to the selected LLM.
5. Receives the generated response.
6. Displays the answer in the terminal.
